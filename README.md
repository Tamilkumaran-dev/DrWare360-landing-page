# DrWare360 Landing Page

Standalone marketing site for DrWare360. It is isolated from the product UI and can be built and deployed independently.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm test
npm run lint
```

## Production

```bash
npm run build
npm start
```

The primary product links point to `https://ui.drware360.com`.
